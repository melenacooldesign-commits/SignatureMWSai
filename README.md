# MWS AI — конструктор корпоративной подписи

Статический сайт: публикуется из корня репозитория на Vercel, GitHub Pages или любом хостинге — всё работает без сборки.

## Структура

```
├── index.html                          ← главная страница (конструктор)
├── css/app.css                         ← стили интерфейса
├── js/app.js                           ← логика конструктора
├── templates/
│   ├── signature.template.html         ← ЭТАЛОН подписи (редактируйте здесь)
│   └── signature-instructions.html     ← инструкции в комментариях для скачиваемого файла
└── examples/
    └── signature.html                  ← готовый пример с данными по умолчанию
```

**Эталон** — `templates/signature.template.html`. Плейсхолдеры: `{{NAME}}`, `{{POSITION}}`, `{{PHONE}}`, `{{EMAIL}}`.

Конструктор подставляет значения в этот файл для превью и для кнопок «Скачать» / «Копировать».

## Публикация на Vercel

1. Импортируйте репозиторий в Vercel.
2. Framework Preset: **Other**.
3. Build Command: оставьте пустым.
4. Output Directory: оставьте пустым или укажите `.`.

Vercel ищет `index.html` в корне проекта. Если положить сайт внутрь дополнительной папки, корневой адрес деплоя будет отдавать `404: NOT_FOUND`.

## Публикация на GitHub

1. Создайте репозиторий (например `mws-ai-signature`).
2. Загрузите файлы из этого репозитория в корень проекта.
3. Settings → Pages → Source: **Deploy from branch** → `main` / `/ (root)`.
4. Сайт откроется по адресу `https://<user>.github.io/<repo>/`.

## Другой хостинг

Скопируйте файлы в корень сайта. Точка входа — `index.html`.

## Локальная проверка

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080

> Двойной клик по `index.html` тоже работает (шаблон подгружается из резервной копии внутри страницы). Для разработки удобнее HTTP-сервер — тогда эталон читается из `templates/`.

## Редактирование подписи

1. Откройте `templates/signature.template.html`.
2. Меняйте вёрстку, логотип, фиксированные строки.
3. При необходимости обновите резервную копию в `index.html` (блоки `#tpl-body` и `#tpl-instructions`) — чтобы офлайн-режим совпадал с эталоном.

Готовый файл без конструктора: `examples/signature.html`.
